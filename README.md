# Car Rental System

A Java-based Car Rental System built with Spring Boot, allowing users to browse, rent, and manage car rentals.

## Tech Stack

| Layer | Technologies |
|-------|-------------|
| Language | Java |
| Framework | Spring Boot, Spring MVC |
| Persistence | Spring Data JPA, Hibernate |
| Database | MySQL |
| Build | Maven |
| Version Control | Git, GitHub |

## Features

- **Car Catalog** — Browse available cars with details (model, price, availability)
- **Rental Management** — Book a car, specify rental duration, calculate cost
- **Customer Management** — Register customers, view rental history
- **Admin Panel** — Add/remove cars, manage bookings, view all rentals
- **Cost Calculation** — Automatic rental cost based on duration and car type

## How to Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/ysurendra25/CarRentalSystem.git
   cd CarRentalSystem
   ```

2. **Configure MySQL** — Update `application.properties` with your database credentials

3. **Build and run**
   ```bash
   ./mvnw spring-boot:run
   ```
